# 可观察验收标准与门禁规范 (ACCEPTANCE.md)

## 1. 验收准则设计原则
所有功能、任务与代码合入必须满足**可观察、可量化、可验证**的明确断言标准。禁止仅凭口头描述声明“功能已就绪”。

---

## 2. 核心功能逐条可观察验收标准 (A01 ~ A10)

### A01 [治理门禁与协作防伪] (对应 R01 / TASK-GOV-001, TASK-GOV-002)
- **输入/前置条件**：仓库处于最新状态，已安装 PowerShell 7+。
- **操作步骤**：在终端运行 `pwsh scripts/governance/check.ps1`。
- **可观察断言**：
  1. 终端输出 `[PASS] CHK-01` 至 `CHK-04`，全绿通过且退出码为 0。
  2. 全套 20+ 份规范文档在 `docs/` 下完整存在，无空文件。
  3. `governance/handoffs/` 下各任务具备合法 SHA256 签名事件链。

### A02 [插件 SDK 标准契约] (对应 R02 / TASK-SDK-001)
- **输入/前置条件**：编译 `SysLens.Sdk.csproj`。
- **可观察断言**：
  1. 输出 `SysLens.Sdk.dll`，0 警告，0 错误。
  2. 运行 `dotnet test tests/SysLens.Sdk.Tests` 全部通过。
  3. 契约中包含完整的 `IToolPlugin`、`IPluginContext`、`IProcessCollectorService` 接口与不可变 DTO 定义。

### A03 [宿主外壳与 Fluent 现代窗口] (对应 R01 / TASK-SHELL-001)
- **操作步骤**：启动 `SysLens.App.exe`。
- **可观察断言**：
  1. 窗口成功渲染 Win11 Mica 材质与圆角效果，无黑边或标题栏渲染撕裂。
  2. 切换系统深色/浅色模式，应用界面在 200ms 内平滑自适应反色，文字对比度正常。
  3. 侧边栏 `NavigationView` 能正确折叠与展开。

### A04 [插件动态隔离加载与沙箱防护] (对应 R02 / TASK-CORE-001)
- **操作步骤**：将测试插件 DLL 放入 `Plugins/` 目录并重启或动态加载。
- **可观察断言**：
  1. 侧边栏成功出现该插件的图标与显示名称。
  2. 在独立 `AssemblyLoadContext` 中完成加载，与宿主依赖版本互不冲突。
  3. 故意放入损坏或抛出异常的 DLL，宿主弹出友好 InfoBar 提示并记录日志，主程序绝不崩溃退出。

### A05 [权限识别与平滑 UAC 提权] (对应 R03 / TASK-CORE-001)
- **操作步骤**：普通用户权限启动应用，观察右上角并点击提权按钮。
- **可观察断言**：
  1. 右上角徽标显示灰蓝色 `[普通权限]`。
  2. 点击提权后弹出 Windows UAC 对话框；点击同意后新实例唤起，旧实例优雅退出。
  3. 新实例右上角徽标变为绿色 `[管理员]`，进程令牌具备完整性。

### A06 [父子进程树层级展现与孤儿收归] (对应 R04 / TASK-PE-001)
- **操作步骤**：打开 CMD 并在其中启动 Notepad，随后在 SysLens 中观察。
- **可观察断言**：
  1. `notepad.exe` 呈现在 `cmd.exe` 的子节点下，缩进 16px。
  2. 关闭 `cmd.exe` 保留 `notepad.exe`，刷新后 `notepad.exe` 优雅回退并挂载于顶层根节点，不丢失不报错。
  3. 单元测试针对成环恶意 PPID 样本运行，验证环路检测算法 100% 拦截并阻断死循环。

### A07 [多核 CPU、内存与 I/O 采样精度] (对应 R05 / TASK-PE-001)
- **操作步骤**：运行高负载多线程测试程序，并在 SysLens 与任务管理器中对比观察。
- **可观察断言**：
  1. CPU 使用率总和稳定在合理范围，单进程多核归一化 CPU % 与任务管理器误差小于 ±2%。
  2. 专用工作集内存数值与任务管理器对应值精准一致。
  3. 连续运行 10 分钟，SysLens 自身句柄占用保持恒定（波动 < 5 个），无任何句柄泄漏。

### A08 [即输即搜极速模糊过滤] (对应 R06 / TASK-PE-002)
- **操作步骤**：在搜索框输入 `sys` 或指定 PID。
- **可观察断言**：
  1. 列表在 50ms 内完成即输即搜过滤，匹配项高亮。
  2. 若子进程匹配，父节点自动展开以显示层级链路。
  3. 清空搜索框后，完整进程树毫秒级恢复原始状态。

### A09 [快捷进程控制与安全防护] (对应 R07 / TASK-PE-002)
- **操作步骤**：分别对临时测试进程（如 `calc.exe`）执行挂起、恢复与结束；并对系统核心进程（如 `csrss.exe`）执行结束。
- **可观察断言**：
  1. 点击“挂起”后计算器无响应，行状态变为灰色；点击“恢复”后恢复正常。
  2. 点击“结束进程”后计算器被即时关闭，列表中该行以淡红色高亮 1 秒后消失。
  3. 对 `csrss.exe` 右键尝试结束时，系统弹出强拦截确认警告框，默认取消，有效阻止误操作。

### A10 [下方面板模块、句柄与线程深度探查] (对应 R08, R09, R10 / TASK-PE-002)
- **操作步骤**：选中任意运行中的普通进程，分别点击下方 Modules、Handles、Threads 标签页。
- **可观察断言**：
  1. **Modules**：完整列出 `ntdll.dll`、`kernel32.dll` 等已加载模块的基地址与绝对路径。
  2. **Handles**：列出 File, Key, Mutant 等系统内核对象句柄；面对包含命名管道的进程，探查在 50ms 内安全返回，主线程 100% 绝不卡死。
  3. **Threads**：显示各线程 TID、优先级与上下文切换次数。
