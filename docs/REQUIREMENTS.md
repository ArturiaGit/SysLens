# SysLens 需求基线 (REQUIREMENTS.md)

## 1. 产品定位
SysLens 是面向 Windows 高级用户、开发者与系统工程师的现代模块化系统工具箱。平台提供现代 Fluent 交互外壳，支持各类系统观测与排障工具的动态挂载，首款核心工具为深度系统进程分析器（Process Explorer）。

---

## 2. 需求条目与编号 (Traceable Requirements)

### 宿主平台需求 (Platform Core)
- **R01 [平台宿主与现代界面]**：提供基于 WinUI 3 + .NET 8 的桌面外壳，支持 Win11 亚克力/云母材质与深浅色模式自适应。
- **R02 [模块化插件扩展体系]**：基于 `AssemblyLoadContext` 提供插件独立隔离加载机制，通过 `IToolPlugin` 标准契约挂载小工具。
- **R03 [特权管理与一键提权]**：自动识别当前权限完整性，提供无缝 UAC 提权重启机制。

### 首款工具：Process Explorer 需求
- **R04 [进程树状层级呈现]**：基于父子进程关系（PID 与 PPID）动态构建多层级进程树，高亮标识新启动与退出中的进程。
- **R05 [高精毫秒级性能指标监控]**：毫秒级多线程采集进程 CPU 使用率（增量计算）、专用工作集/提交内存、I/O 读写速率、句柄数与线程数。
- **R06 [即输即搜过滤]**：支持在千量级进程列表中实时毫秒级按进程名、PID 快速模糊过滤。
- **R07 [快捷进程管理操作]**：提供右键操作菜单，支持“结束进程”、“结束进程树”、“挂起进程”、“恢复进程”、“定位文件位置”。
- **R08 [下方面板：已加载模块 (DLL)]**：检查选定进程已载入的 32/64 位 DLL 模块列表，显示基地址、大小、版本与厂商信息。
- **R09 [下方面板：打开句柄 (Handle)]**：枚举目标进程打开的系统句柄，显示句柄值、对象类型（File, Key, Mutant, Section, Event）与对象路径。
- **R10 [下方面板：活动线程 (Thread)]**：枚举目标进程的线程列表，显示 TID、优先级、上下文切换次数与入口地址。
