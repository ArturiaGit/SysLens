# SysLens 需求基线与业务场景规范 (REQUIREMENTS.md)

## 1. 产品定位与目标受众
SysLens 是一款面向 Windows 10/11 平台高级系统工程师、逆向安全研究员、软件性能优化师与极客用户的现代化系统排障与诊断工具箱。
其首款核心工具为深度系统进程分析器（**Process Explorer**），旨在以现代化 Fluent 交互与毫秒级低开销引擎，替代传统 Sysinternals Process Explorer 的日常诊断场景。

## 2. 需求条目与用户故事清单 (Traceable Requirements)

### 宿主平台需求 (Platform Core)

#### R01 [宿主外壳与现代 Fluent 体验]
- **用户故事**：作为系统运维人员，我希望工具箱界面契合 Windows 11 现代视觉风格（支持 Mica 背景、亚克力半透明与自适应暗色/亮色主题），以便在长时间排障诊断时获得舒适、清晰的视觉体验。
- **功能细节**：
  - 自适应系统主题切换（Dark / Light），响应无需重启。
  - 自定义无边框沉浸式 TitleBar，集成全局快速搜索框与管理员权限胶囊。
  - 侧边栏采用 `NavigationView` 折叠/展开形态。

#### R02 [微内核插件隔离加载机制]
- **用户故事**：作为后续扩展开发者，我希望每个小工具以独立程序集或插件包形式挂载，互不干扰且不污染宿主程序，以便持续开发网络、注册表、服务管理等后续模块。
- **功能细节**：
  - 基于 .NET 8 `AssemblyLoadContext` 实现插件独立加载与物理依赖隔离。
  - 插件仅依赖 `SysLens.Sdk` 标准接口（`IToolPlugin`, `IPluginContext`）。
  - 支持插件错误捕获防崩溃（沙箱保护），单插件加载失败不影响宿主其他功能。

#### R03 [平滑 UAC 权限识别与一键提权]
- **用户故事**：作为普通用户，我希望默认以安全受限权限运行，仅在需要探查内核句柄或终止特权进程时一键无缝提权，以便兼顾日常安全性与排障特权需求。
- **功能细节**：
  - 启动时自动通过 Token Elevation 探测当前完整性等级并在右上角显示 `[普通权限]` 或 `[管理员]`。
  - 点击右上角胶囊即可弹出提权确认并调用 `runas` 平滑重启新实例，旧实例优雅退出。

### 首款工具：Process Explorer 需求 (Process Engine & UI)

#### R04 [父子进程树层级展现与拓扑重构]
- **用户故事**：作为排障工程师，我希望按父子进程关系树状查看正在运行的进程，以便迅速定位恶意进程派生链或故障子进程（如 CMD 派生的恶意脚本）。
- **功能细节**：
  - 根据 PID 与 ParentPID 实时递归构建层级进程树，子进程阶梯缩进 16px。
  - 当父进程已退出时，孤儿进程优雅收归并挂载于顶层根节点，绝不丢失。
  - 具备环形引用防御（防御恶意篡改 PPID 导致的无限递归死循环）。

#### R05 [毫秒级多核 CPU、内存与 I/O 增量监控]
- **用户故事**：作为性能调优师，我希望实时观察各个进程的 CPU 占用率（多核归一化）、私有工作集内存、提交大小与 I/O 读写速率，以便准确捕获异常高负载进程。
- **功能细节**：
  - 后台采样周期支持 1.0s（默认）、0.5s（高精）、2.0s（节能）与暂停。
  - CPU 使用率基于前后两轮采样的内核态与用户态增量计算：`Delta(Kernel + User) / Delta(SystemTime) / Cores`。
  - 内存指标精准区分专用工作集（Private Working Set）与提交内存（Commit Charge）。
  - 实时统计每个进程的系统句柄总数与活动线程总数。

#### R06 [即输即搜极速模糊过滤]
- **用户故事**：作为应急响应人员，我希望在千量级进程中输入关键词即可毫秒级锁定目标，以便快速处置疑似进程。
- **功能细节**：
  - 标题栏与工具栏提供搜索框，支持快捷键 `Ctrl + F` 快速聚焦。
  - 按进程映像名（如 `chrome`）与 PID（如 `1234`）即输即搜实时过滤。
  - 命中子节点时自动展开父节点并在树中保持上下文关联。

#### R07 [快捷进程控制与安全防护]
- **用户故事**：作为系统运维人员，我希望在进程行上右键快捷终止、挂起或恢复进程，以便迅速冻结或清理失控程序。
- **功能细节**：
  - 右键上下文菜单提供：结束进程（`TerminateProcess`）、结束进程树（递归结束所有子孙进程）、挂起进程（`NtSuspendProcess`）、恢复进程（`NtResumeProcess`）、打开文件所在位置。
  - **安全防范**：针对系统关键进程（PID 0, PID 4, `csrss.exe`, `lsass.exe`, `wininit.exe`）弹出高危拦截确认对话框，防止系统蓝屏（BSOD）。

#### R08 [下方面板：已加载模块 (DLL) 深度枚举]
- **用户故事**：作为逆向工程师，我希望查看目标进程已加载的所有 DLL，以便检查是否有注入的可疑模块。
- **功能细节**：
  - 支持同时枚举 32 位与 64 位进程的模块列表（`EnumProcessModulesEx`）。
  - 呈现模块基地址、大小、磁盘绝对路径、版本号、产品描述与公司名称。

#### R09 [下方面板：打开句柄 (Handle) 深度探查]
- **用户故事**：作为系统分析师，我希望查看目标进程占用了哪些文件、注册表项或互斥体句柄，以便排查文件被占用锁死无法删除的问题。
- **功能细节**：
  - 基于 `NtQuerySystemInformation` 与 `DuplicateHandle` 枚举句柄。
  - 显示句柄数值、对象类型（File, Key, Section, Mutant, Event, ALPC Port 等）、对象路径与授权访问掩码。
  - 具备针对挂起的同步命名管道（Synchronous Named Pipe）句柄的挂死超时防御保护。

#### R10 [下方面板：活动线程 (Thread) 状态检查]
- **用户故事**：作为调试人员，我希望查看选定进程的各个线程执行状态与优先级，以便分析死锁与线程卡死原因。
- **功能细节**：
  - 枚举所有活动线程的 TID、动态优先级、基本优先级、状态（Running / Waiting）、上下文切换次数与起始入口地址。
