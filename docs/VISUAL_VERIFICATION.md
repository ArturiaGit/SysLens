# 视觉验证与 UI 交互实测规范 (VISUAL_VERIFICATION.md)

## 1. 测试环境与设备矩阵
所有针对前端界面的测试验证必须在以下条件下进行观察：
- **操作系统**：Windows 11 (Build 22000+) 与 Windows 10 (Build 19041+)
- **显示器 DPI 缩放**：100% (标准 1080p), 125%, 150% (高分屏), 200% (4K 屏幕)
- **色彩模式**：Windows 系统设置下的浅色模式 (Light) 与深色模式 (Dark)

---

## 2. 视觉与交互实测检查矩阵 (Visual Verification Matrix)

| 编号 | 验证场景 | 操作步骤 | 预期视觉效果与断言标准 |
|---|---|---|---|
| **VV-01** | 主题即时自适应 | 在系统设置中切换深色/浅色模式 | 应用无需重启，Mica 窗口背景、文字前景色与边框线平滑过渡，无视觉反色异常 |
| **VV-02** | 自定义 TitleBar | 鼠标拖拽标题栏、双击最大化、还原 | 窗口拖拽响应灵敏；标题文字、图标及管理员徽标与窗口控制按钮（最小化/最大化/关闭）无重叠 |
| **VV-03** | 树形网格缩进 | 展开有子进程的节点（如 `explorer.exe`） | 子节点阶梯式向右缩进 16px，折叠/展开指示三角动画顺畅无顿挫 |
| **VV-04** | 增量着色高亮 | 启动一个新进程（如打开记事本） | 列表中新出现的记事本行背景瞬间呈现淡绿色高亮，1 秒后渐变淡出至正常底色 |
| **VV-05** | 消亡进程高亮 | 关闭记事本 | 该行背景变为淡红色高亮，保留 1 秒后平滑移出列表，无列表跳动抖动 |
| **VV-06** | 即输即搜过滤 | 在搜索框输入关键词（如 `chrome`） | 列表毫秒级仅保留匹配名称或 PID 的行，父进程匹配时高亮，清空搜索时立即还原全量树 |
| **VV-07** | 右键上下文菜单 | 选中任意进程右键点击 | 菜单在鼠标点击处弹出，样式遵循 Win11 圆角阴影风格，快捷键提示（如 Delete）对齐整齐 |
| **VV-08** | 分割条拖拽 | 鼠标拖拽中间的水平 Splitter 调整上下比例 | 上方进程树与下方详细面板按拖拽比例平滑缩放，下方面板高度最小保护生效（不被压至 0） |
| **VV-09** | 详细检查器标签切换 | 在下方点击 Modules / Handles / Threads 标签 | 标签切换无延迟，网格数据秒级呈现，表头可点击按列排序（如按模块大小排序） |
| **VV-10** | 管理员徽标与提权 | 普通模式下点击标题栏 `[普通权限]` 徽标 | 弹出提权确认对话框；确认后 UAC 窗口弹出，提权重启后的新实例右上角呈现绿色 `[管理员]` |

## 3. 实机截图证据归档标准
在完成每项前端界面的任务交付时：
1. 必须捕获包含上述验证场景的关键界面截图；
2. 存入 `docs/verification/` 目录下；
3. 在单篇变更文档（`docs/changes/`）的“验证证据”章节建立图片超链接并记录测试结论。
